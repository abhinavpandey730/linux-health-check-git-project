# Linux Server Health Check Project

## About
This project is designed to monitor basic Linux Server Health.

## Feature
- CPU Usage Monitoring
- Memory Usage Monitoring
- Disk Usage Monitoring
- Service Status Monitoring
- Health Report Generation

## Technologies
- Linux 
- Bash Shell Scripting
- Git
- GitHub

## Git Workflow
This project uses Git for version control and GitHub
for remote repository hosting and collaboration.
